### Projects

**PX4 track pacing** · `ROS 2 · PX4 · MAVROS · Gazebo`<br>
A drone flies laps of a running track on its own, with route, speed and height set in a config
file. Laps 2 and 3 hold the same line within 6 cm (PX4 flight log).
[Video](https://www.youtube.com/watch?v=wvMxqPTPmhs)

**Mengabot** · `ROS 2 · Gazebo Harmonic`<br>
A modular multi-robot simulation platform: robot models, worlds and fleets chosen in one command.
[Video](https://www.youtube.com/watch?v=wurXI_GgwnE)

**[pf-sampling](https://github.com/berito/pf-sampling)** · `Python · Docker`<br>
How the sampling choices inside a particle filter (resampling scheme and timing, FastSLAM 1.0 vs
2.0 proposals, particle count, MCMC moves) change accuracy, degeneracy and runtime, on robot
localization and SLAM. Experiments in progress.

Freelance work on Upwork (Top Rated): 3D LiDAR-inertial SLAM for a Unitree L2 sensor (Point-LIO
with a GTSAM pose-graph back-end), and Nav2 tuning that reached 30 of 30 runs on the walls map
and 26 of 30 with obstacles.
